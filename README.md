# CTN Score

Hệ thống mô phỏng quản lý thi đua Đoàn trường THPT Chuyên Thái Nguyên.

## Demo features
- Tổng quan & xếp hạng 39 lớp / 35 tuần
- Class Detail và Score Breakdown
- Rule Engine có version, scope, source
- Score Transactions
- Vi phạm và Sổ đầu bài
- Thành tích / sự kiện
- Đoàn viên và Member Profile
- Trực tuần
- Duyệt transaction
- Audit Log
- Integrity Check
- Demo data generator
- Role switcher

## Tech stack
HTML · Tailwind CSS CDN · Vanilla JavaScript · Chart.js · LocalStorage

## Demo data
Dữ liệu là dữ liệu mô phỏng. Các luật có `source=REFERENCE` được gắn nhãn nguồn tham khảo; các luật `DEMO` chỉ phục vụ minh họa và không được hiểu là quy định hiện hành của nhà trường.

## Run
Mở `index.html` bằng trình duyệt hoặc dùng Live Server. Bấm **Khởi tạo / làm mới Demo** để tạo dữ liệu.
